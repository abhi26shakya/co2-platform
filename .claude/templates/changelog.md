# Versioning Policy

Version numbers follow:

```
MAJOR.MINOR.PATCH
```

Examples:

```
1.0.0
1.2.0
1.2.5
2.0.0
```

Definitions:

**MAJOR**

Breaking changes.

**MINOR**

Backward-compatible new features.

**PATCH**

Backward-compatible bug fixes.

- Do not remove historical entries.
- Follow Semantic Versioning.
- Keep migration notes accurate.
- Document breaking changes clearly.
